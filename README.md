# Portfolio – Dzhan Pekdzhan

Mijn persoonlijke portfolio. Ik studeer Toegepaste Informatica aan de Karel de Grote Hogeschool in Antwerpen, en op deze site laat ik zien aan welke projecten ik gewerkt heb.

Gemaakt met **React** en **Vite**, met gewone CSS.

🌐 Live: https://canpekcan1905.github.io/Portfolio/

De site wordt automatisch gepubliceerd op GitHub Pages bij elke push naar `main` (zie `.github/workflows/deploy.yml`).

## Lokaal starten

```bash
npm install
npm run dev
```

Daarna open je de link die in de terminal verschijnt (meestal http://localhost:5173).

## Structuur

```
src/
├── App.jsx          → zet alle secties onder elkaar en regelt het thema
├── index.css        → kleuren, lettertypes en algemene stijl
├── onderdelen/      → elke sectie van de pagina (navigatie, projecten, contact, ...)
├── haken/           → eigen React-hooks (scrollen en fade-in animaties)
└── assets/          → foto's en screenshots
```
